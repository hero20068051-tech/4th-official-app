# 4th Official App - Project Rules v0.2

第4審判向け交代管理Webアプリの Phase 1 開発用基準資料です。

最初に読む：
`PROJECT_RULES/00_READ_FIRST.md`

- `PROJECT_RULES/`：Claude Code が毎回の作業前に確認する基準
- `SPEC/`：Phase 1 の実装仕様とテストケース

状態：
- **LOCKED**：基本思想。ユーザー確認なしに変更禁止
- **CONFIRMED**：大会要項・確認済み運用・ユーザー決定として確定
- **PENDING**：未確認。推測実装禁止
- **FUTURE**：将来候補。Phase 1へ勝手に追加しない

## v0.2 の主な更新
- HOME / AWAYそれぞれの仮入力を保持
- 確定前は自由に選び直し、確定後は履歴から修正
- 履歴修正後の全再計算と、後続イベント不整合の警告
- ローカル自動保存と再開
- 実時間ベースの試合時計と開始時刻修正
- 飲水運用（なし / ランニング / 時計停止）を試合前設定へ追加
- 7〜10人でも警告付きで試合開始可能、6人以下は開始不可
- キックオフ前の先発変更は試合中の交代に数えない
- 背番号一括入力・重複禁止・数値順表示
- `isGoalkeeper` を `isRegisteredGK` に明確化
- 「9名」「後半3回」「再交代3名」を別概念として管理
- 実戦テストケースを追加
