# 【PENDING】確認中・推測実装禁止

## 同一選手の複数回再出場
例：
10番 先発
→ OUT
→ 10番 再出場
→ 再びOUT
→ 10番がもう一度再出場できるか？

中村氏へ確認中。

### 未確定のため決めてはいけないこと
- 2回目以降の再出場を許可する / 禁止すること。
- 同一選手が複数回再出場できる場合、「再交代3名」の上限をどのように数えるか。

回答が確定するまで独自解釈で実装しない。
この条件は差し替え可能な独立ロジックとして設計する。

## PENDINGではない事項
次はすでに別途整理済みなので、再び未確定扱いに戻さない。
- HTで最後の未出場FPを出し、同じHT内で再出場するケース：中村氏の運用回答あり。
- 飲水：その日のマッチミーティングで決定するため、試合ごとの設定として扱う。
