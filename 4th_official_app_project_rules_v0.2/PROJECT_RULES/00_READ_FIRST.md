# 00_READ_FIRST

このフォルダは、第4審判向け交代管理Webアプリの「作業前に必ず確認する基準資料」です。

## 作業ルール
1. 【LOCKED】は勝手に変更しない。
2. 【CONFIRMED】は確定済みとして扱う。
3. 【PENDING】は推測で実装しない。
4. 【FUTURE】は構想として保持するが、Phase 1へ勝手に追加しない。
5. 既存仕様と矛盾する変更が必要な場合は、実装前にユーザーへ確認する。
6. 「便利そうだから」という理由だけで機能を追加しない。
7. Phase 1は「シンプルだが必要なものは確実に対応」を優先する。
8. 専門用語より、初めて使う人や中学生にも分かる言葉を優先する。
9. アプリが判断できることを利用者へ質問しない。
10. アプリは主審・大会運営の最終判断を置き換えない。
11. 未確認ルールを一般的な競技知識で補完しない。
12. 毎回の作業前に、次を番号順に読む。

- `01_LOCKED_PRINCIPLES.md`
- `02_CONFIRMED_RULES.md`
- `03_PHASE1_SCOPE.md`
- `04_PENDING.md`
- `05_FUTURE_IDEAS.md`
- `../SPEC/Phase1_Spec_v0.2.md`
- 必要に応じて `../SPEC/TEST_SCENARIOS_v0.1.md`
