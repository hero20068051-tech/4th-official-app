# 02_CONFIRMED_RULES

# 【CONFIRMED】確定しているルール・運用

## A. 大会要項で確認できる事項
対象：2026年度 第34回埼玉県女子サッカーリーグ大会実施要項

- JFA競技規則 2025/2026 による。
- 1部：70分（35分ハーフ）。
- 2部：60分（30分ハーフ）。
- ハーフタイム：10分。
- 第4審は、本部担当ではないもう片方のチームが担当する。
- 本部担当チームは試合の記録を担当する。
- 試合時の人数は7名以上。
- 試合登録は20名以内。
- 交代要員から9名以内を前後半を通じて使用できる。
- 条件付きの再交代（リエントリー）がある。
- 出場した選手を再び出場させる場合、FP側の交代要員が全員出場済みであることが条件となる。
- GK登録選手は上記FP側の条件では別枠として扱う。
- ハーフタイム以降、再交代できる選手は3名まで。
- 後半開始後の交代は、再交代を含め3回まで。
- 脳震盪に関する交代はJFA競技規則第3条に従う。ただしPhase 1では専用処理を実装しない。
- メンバー表提出後からキックオフ前に先発予定選手が出場できなくなった場合、登録済み交代要員との変更が認められる。交代要員リストの補充・変更はしない。

## B. 中村氏への確認で運用上確認できた事項
- HTの交代は「後半の交代3回」に数えない。
- 後半開始のホイッスル後から3回を数える。
- 同じタイミングで複数人を交代しても、そのチームは1回として数える。
- 後半3回を使い切ったら、その後の通常交代・再出場は行わない。
- まだ出場していないFP交代要員がいる場合、すでにOUTしたFP選手はまだ再出場できない。
- GK登録選手が未出場でも、FP側の「全員出場」条件を妨げない。
- 前半終了までに条件を満たしていれば、HTで再出場できる。
- HTでの再出場も後半3回には数えない。
- HTで最後の未出場FP交代要員を出場させて条件を満たし、その同じHT中に再出場を行う運用は可能との回答を得ている。
  - ただしこの点は大会要項の明文ではなく、中村氏の運用認識に基づくものとして記録する。

## C. 飲水に関する当日運用
- 今回の要項には、飲水タイムの有無・時刻・時計の扱いの具体的記載はない。
- 中村氏から「飲水についてはその日のマッチミーティングで決まる」との回答あり。
- よってアプリでは、試合ごとの設定として扱う。

Phase 1の設定値：
1. 飲水なし
2. 飲水あり・ランニング（試合時計を止めない）
3. 飲水あり・時計停止

飲水を取る目安時刻は任意メモとし、固定ルールにはしない。

## D. ユーザー決定による試合開始人数
- 先発11名：通常開始。
- 先発7〜10名：警告を表示したうえで開始可能。
- 先発6名以下：開始不可。

## E. アプリ内部の分類
### 通常交代
INする選手が、その試合でまだ一度も出場していない場合。

### 再出場
INする選手が、すでに出場し、その後ベンチにいる場合。

**利用者にはこの分類を選ばせない。**

## F. 「9 / 3 / 3」は別概念
混同しないこと。

- **9名**：前後半を通じて使用できる交代要員の人数に関する上限。
- **3回**：後半開始後の交代機会の上限。同時に複数人交代しても1回。
- **3名**：ハーフタイム以降に再交代できる選手数の上限。

同一選手の複数回再出場が可能か、およびその場合の「3名」の数え方は【PENDING】。
